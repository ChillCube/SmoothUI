# SmoothUI

A base node for smooth UI nodes used by ChillCube

## Installation

Make sure to download the ChillCube Developer tools: https://github.com/ChillCube/ChillCube-Developer-Tools.git

### Using the Godot Plugin
Enable the **ChillCube Tools** plugin, then paste the repo URL into the Clone tab.

### Linux / CLI
```bash
clone-gd-addon https://github.com/ChillCube/SmoothUI.git
```

## Documentation
https://github.com/ChillCube/SmoothUI/blob/main/DOCUMENTATION.md

## Deinstallation
Use the CC Tools panel in Godot, or run:
```bash
remove-gd-addon SmoothUI
```

## For Developers
```bash
push-all-addons
```
